# Documentation guide

Start with the repository [README](../README.md) for the five-minute overview, commands, URLs, and expected
results. Reviewers do not need to read every document; the recommended order is:

1. [Architecture](architecture.md) — services, data flow, ontology, boundaries, and technical tradeoffs.
2. [AFDD semantics](afdd.md) — targeting, timing, lifecycle, overrides, and persisted evidence.
3. [AI authoring](ai-authoring.md) — trust boundary, state machine, live-provider results, and safety.
4. [Demonstration guide](demonstration-guide.md) — 5–10 minute reviewer journey and screenshot map.
5. [Validation report](validation-report.md) — deterministic results and requirement coverage.
